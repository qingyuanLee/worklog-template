# 工作日志格式规范（worklog-format）

依据用户既有幕布文档《2026--Agent爆发之年》（工作/朋熙）的实际记录习惯提炼。生成任何工作日志模板时，严格遵循以下规则。

## 1. 文档结构（幕布大纲，逐级展开）

```
# MMDD-MMDD          ← 周标题（第1层节点，一个连续工作日跨度）
- DD                ← 工作日日期节点（第2层，仅写日号）
  - 工作事项        ← 内容节点（第3层起，可多级）
    - 子任务/备注
> 周备注            ← 备注（挂在周标题节点，幕布 note 字段）
```

- 第 1 层：周标题节点，平铺排列（幕布文档的多个顶层节点），不嵌套。
- 第 2 层：日期节点 `- DD`（如 `- 4`、`- 12`、`- 28`）。
- 第 3 层起：该日的工作事项、任务清单，层级任意。
- `> 引用行`：周备注，挂在最近周标题节点上（对应幕布 note 字段）。

## 2. 周标题命名规则

- 基本格式：`# MMDD-MMDD`，表示该组连续工作日的起止日期，如 `# 0104-09`（1月4日至9日）。
- 周跨度 = 连续工作日（含调休上班的周末日，不含双休与节假日）。
- 跨月周：标题仍用 `MMDD-MMDD`，如 `# 0330-0403`、`# 0629-0703`、`# 1130-1204`。
- 特殊后缀（追加在标题后）：
  - 节假日周：`-节假日假期`，如 `# 0213-23-春节假期`（该周无日期节点）。
  - 请假：`【N号请假】`，如 `# 0713-17【17号请假】`。
  - 加班：`-加班`，如 `# 0815-加班`。
  - 单日周：`# MMDD`，如 `# 0530`（周六调休上班/加班日）。

## 3. 日期节点命名规则

- 同月内：`- DD`（只写日号），如 `- 12`、`- 30`。
- 跨月周：进入新月份的首日节点写 `- MMDD`（月+日，不带补零分隔），之后同月内恢复 `- DD`。
  - 例：`# 0330-0403` → `- 30`、`- 31`、`- 0401`、`- 02`、`- 03`
  - 例：`# 1130-1204` → `- 30`、`- 1201`、`- 02`、`- 03`、`- 04`
- 未来未记录的工作日：只生成空日期节点（无子节点），内容留待填写。

## 4. 节假日节点规则

- 非双休的国家节假日（法定假日当天不在周六/周日，或假期含工作日）需要单独成节点。
- 格式：`# MMDD-MMDD-节假日假期`，无日期子节点；可附一条备注（note）写明官方放假安排。
  - 例：`# 0101-03-元旦假期`、`# 0404-06-清明节假期`、`# 0501-05-劳动节假期`、
    `# 0619-21-端午节假期`、`# 0925-27-中秋节假期`、`# 1001-07-国庆节假期`。
- 按时间顺序插入到对应周标题之间，保持全年时间线完整。
- 备注（官方安排描述）格式参考：`清明节：4月4日（周六）至6日（周一）放假，共3天`。

## 5. 其他约定

- 双休日（周六、周日）除非调休上班或加班，否则不生成节点。
- 文档按周推进，最后一组可能是不满 5 天的周（如 `# 1228-31`，12月28日周一至31日周四）。
- 内容层级用 Markdown 缩进表示：每级 2 空格，`#` 为第 1 层，`- ` 列表为第 2 层起。
