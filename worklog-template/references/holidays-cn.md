# 中国法定节假日安排参考

## 官方来源

国务院办公厅每年 11 月发布次年《关于部分节假日安排的通知》（国办发明电〔20XX〕X号）。
**生成模板前必须用当年官方通知核实，不要只依赖本文件**（本文件内置 2026 年数据，其他年份需替换）。

- 中国政府网历年通知检索：https://www.gov.cn/zhengce/zhengceku/ 或搜索「国务院办公厅 关于 YYYY 年部分节假日安排的通知」

## 2026 年安排（国办发明电〔2025〕7号，2025-11-04 发布）

来源：https://www.gov.cn/zhengce/content/202511/content_7047090.htm

| 节假日 | 放假调休日期 | 天数 | 调休上班日 |
|---|---|---|---|
| 元旦 | 1月1日（周四）至3日（周六） | 3 | 1月4日（周日） |
| 春节 | 2月15日（周日）至23日（周一） | 9 | 2月14日（周六）、2月28日（周六） |
| 清明节 | 4月4日（周六）至6日（周一） | 3 | 无 |
| 劳动节 | 5月1日（周五）至5日（周二） | 5 | 5月9日（周六） |
| 端午节 | 6月19日（周五）至21日（周日） | 3 | 无 |
| 中秋节 | 9月25日（周五）至27日（周日） | 3 | 无 |
| 国庆节 | 10月1日（周四）至7日（周三） | 7 | 9月20日（周日）、10月10日（周六） |

## 2026 年工作日/非工作日速查

- 2026 全年调休上班日（周六/周日上班）：1月4日、2月14日、2月28日、5月9日、9月20日、10月10日，共 6 天。
- 2026 年 10 月 9 日之后（截至 12 月 31 日）无任何国家节假日与调休，全部为常规周一至周五工作日。
- 2026 年元旦后首个工作日为 1月4日（周日，调休上班）。

## 非双休节假日判断（用于决定是否生成节假日节点）

"非双休"= 法定假日当天不是周六/周日（或假期含工作日）。

| 节假日 | 法定日 | 是否非双休 | 说明 |
|---|---|---|---|
| 元旦 | 1月1日（周四） | 是 | 假期 1/1-3 含工作日 |
| 春节 | 2月17日（周二，正月初一） | 是 | 假期 2/15-23 含工作日 |
| 清明 | 4月5日（周日） | 按用户口径算 | 假期 4/4-6 含周一 4月6日，用户要求算非双休补齐 |
| 劳动节 | 5月1日（周五） | 是 | 假期 5/1-5 含工作日 |
| 端午 | 6月19日（周五） | 是 | 假期 6/19-21 含工作日 |
| 中秋 | 9月25日（周五） | 是 | 假期 9/25-27 含工作日 |
| 国庆 | 10月1日（周四） | 是 | 假期 10/1-7 含工作日 |

## 反推验证（与用户既有文档交叉核对）

用户文档《2026--Agent爆发之年》的周标题与官方安排一致，可作验证样例：
- `# 0104-09` 含周日 1月4日（元旦调休上班）✓
- `# 0224-28` 含周六 2月28日（春节调休上班）✓
- `# 0506-09` 含周六 5月9日（劳动节调休上班）✓
- `# 0920-24` 含周日 9月20日（国庆调休上班）✓
- `# 1008-11` 含周六 10月10日（国庆调休上班）✓
- `# 0530` 单日周六 5月30日（加班/特殊工作日）✓
- 清明（0404-06）、五一（0501-05）、端午（0619-21）、中秋（0925-27）、国庆（1001-07）在原文中被跳过，生成模板时需按时间补齐。

## 注意事项

- 每年安排不同（2026 年放假调休共 33 天，比 2025 年多 5 天），新年度必须换用新数据。
- 生成模板时用 calculator 工具逐日核算星期，不要凭记忆推算。
